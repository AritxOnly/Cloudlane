# 照片助手

开发路线：逻辑优先，Android 首端，自用；KMP 暂不建立独立模块，纯 Kotlin 规则无 Android 依赖，后续可提取。其他平台不适用。

目标：夜间充电同步 iCloud 与安卓；筛选过期截图和重复图片；明确删除范围并防止回流。
首个实施阶段：真实本地相册扫描、端侧中文 OCR 分类、截图复查、精确重复检查、保留名单、系统回收站、夜间分析、MIUIX 玻璃导航。提供只读 iCloud 验证脚本。云端同步未完成，不以本地分析冒充同步。

验收：
- AC1 读权限不足有明确提示，绝不从缺失照片推断云端删除。
- AC2 截图年龄只作为复查理由；验证码/优惠券结合 OCR；保护名单永不推荐。
- AC3 精确重复必须完成全文件 SHA256；相似度不作为删除依据。
- AC4 删除经用户选择与系统确认；结果刷新，无后台自动删除。
- AC5 充电夜间任务分批检查、可取消；仅 00:00–07:00 开始，错过等待下一窗口。
- AC6 UI 使用 MIUIX Scaffold；玻璃完整源闭包，内容独立录制，共享 backdrop；独立扫描按钮。
- AC7 iCloud 上传、下载、映射、删除日志与恢复必须真实验证，当前未完成。

约束：首版 Android 13+；仅照片；视频/动态照片待协议验证；默认原图，禁止静默转 JPEG。完整清理需完整相册权限。首次扫描可分多次完成。夜间时间以手机本地时区为准。


## 背景

个人使用 iCloud 与安卓，夜间充电整理照片。

## 开发路线

逻辑优先，Android 首端；本轮建立真实本地分析阶段，整体同步持续跟踪。

## 目标

本地截图分析、精确重复检查、保留名单、系统回收站、夜间任务及 MIUIX 页面。

## 非目标

本轮不宣称 iCloud 同步完成，不自动删除云端，不实现视频/动态照片转换。后续同步仍为总需求必做项。

## 用户场景

授权相册后扫描，查看理由与原图，选择清理或保留；夜间充电自动处理新批次。

## 验收标准

AC1–AC7 见上文。原型先行；真实数据接入；规则测试和构建证据独立记录。

## 风险与约束

非官方 iCloud 协议；Android 后台调度；完整扫描需完整照片权限；只支持 Android 13+。

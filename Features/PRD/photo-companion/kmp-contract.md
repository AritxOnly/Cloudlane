# 规则契约

当前纯 Kotlin 函数承担截图分类、夜间窗口和重复分组；Android 平台负责权限、文件读取、OCR 和系统回收站。KMP 模块未开始，其他平台不适用。
照片状态：本地 URI、修改时间、内容哈希、结构化 OCR 信号（截图/保护文档/临时码/截止日期，不含全文）、候选理由、用户保留、扫描完成。权限拒绝为错误状态，不写空列表取代已有状态。OCR/读取失败下次重试。取消不吞异常。
未来同步契约：远端 asset ID + account/library + 本地 URI 映射；pending-upload、awaiting-index、verified、pending-trash、partial-failure 状态；每端操作独立确认。当前尚未实现。
持久化版本 2；禁止破坏性升级，后续需显式迁移；卸载会删除本地索引，重新建立时禁止推断删除。


## 现有能力与缺口

本地分析已接入，iCloud 登录及同步状态机缺失。

## 接口与状态

PhotoRules 输出可解释候选；PhotoIndex 保存内容哈希、分类、保留与分析日；LibraryState 暴露加载和错误。

## 错误与异步语义

取消传播；读取/OCR 失败不缓存成功；权限失败不推断删除；全局 Mutex 防止双扫描。

## 平台接入

Android MediaStore/ML Kit/WorkManager；纯规则可后续提取 KMP，当前无共享模块。

## 兼容与迁移

SQLite v2；v1 → v2 增加结构化信号列，保留 URI、哈希与保留名单，旧索引只重新分析一次；升级必须显式迁移；未实现远端删除，卸载丢失本地索引后不得推断删除。

未修改照片的哈希与 OCR 信号跨天复用；每次扫描仅根据年龄与日期重新判定，避免大相册重复占用每批 80 张额度。回退 v1 APK 前需备份索引；不支持直接降级数据库，也不自动清空数据。
